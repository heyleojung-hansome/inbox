# 씽씽 직업 자동차 🏙️

8살 아이가 바로 즐길 수 있는 3D 로우폴리 도시 자동차 게임입니다. 도시에서 일하는 자동차를 3인칭 시점으로 직접 운전하며 임무를 수행하고, 코인을 모아 새 자동차를 엽니다.

- `index.html` : 3D 버전 (Three.js r128, cdnjs에서 로드)
- `classic-2d.html` : 처음 만든 2D 탑다운 버전

## 자동차와 임무
| 자동차 | 해제 비용 | 임무 | 보상 |
|---|---|---|---|
| 🚓 경찰차 | 무료 | 도망가는 도둑 차를 쫓아가 잡기 | 🪙 12 |
| 🚕 택시 | 무료 | 손님을 태워 목적지까지 | 🪙 10 |
| 🚑 구급차 | 20 | 다친 사람을 태워 병원으로 | 🪙 14 |
| 🚒 소방차 | 30 | 불난 가게 앞에서 💦 버튼을 꾹 눌러 불 끄기 | 🪙 16 |
| 🚚 택배차 | 40 | 물류창고에서 택배를 싣고 집까지 배달 | 🪙 14 |
| 🚛 청소차 | 50 | 길에 떨어진 쓰레기 5개 치우기 | 🪙 18 |
| 🚌 버스 | 60 | 정류장 3곳 순서대로 돌기 | 🪙 20 |
| 🛻 견인차 | 80 | 고장난 차를 정비소로 끌고 가기 | 🪙 22 |

임무마다 ⭐ 별 1개도 함께 받습니다. 별, 코인, 해제한 자동차는 브라우저에 저장됩니다.

## 조작
- 화면: 왼쪽 아래 운전대를 손가락으로 돌려 조향(최대 ±135°), 오른쪽 아래 ⚡가속 / 🛑멈춤 페달(멈춘 뒤 계속 누르면 후진), 특별 버튼(🚨 사이렌 / 💦 물 / 📣 경적)
- 키보드: ← → 핸들, ↑ 가속, ↓ 브레이크, 스페이스 = 특별 버튼, M = 소리 끄기, Esc = 차고로

## 주행 물리
- 자전거 조향 모델: 회전 속도 = 속도 ÷ 축거 × tan(핸들각). 빠를수록 최대 핸들각이 줄어 고속에서도 부드럽게 꺾입니다.
- 스로틀은 페달을 누르면 서서히 차오르고, 속도가 높을수록 가속이 줄어드는 토크 곡선을 씁니다. 페달을 떼면 구름 저항으로 천천히 감속합니다.
- 운전대에서 손을 떼면 속도에 비례한 속도로 스스로 중앙으로 돌아옵니다.

## 화면 구성
- 물리 기반 재질(MeshStandardMaterial)과 캔버스 큐브 환경맵으로 차체 광택, 유리, 크롬 범퍼와 휠 표현
- ACES 톤매핑, sRGB 출력, 그라데이션 하늘 돔, 아스팔트/잔디/보도 노이즈 텍스처
- 건물 창문 텍스처(프레임, 불 켜진 창), 지붕 에어컨·물탱크·안테나, 상점 차양, 연석
- 3인칭 추적 카메라(조향 시 살짝 옆으로 이동), 그림자, 안개, 흘러가는 구름, 원형 속도 게이지
- 우측 상단 미니맵 (내 위치와 목표 표시), 노란 안내 화살표, 목표까지 거리
- 차고에서 회전하는 3D 자동차 미리보기와 속도·힘 스탯

## 실행
`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. Three.js와 Jua 글꼴은 CDN에서 불러옵니다.

# 돌돌 바둑교실 (`baduk/`)

바둑을 전혀 모르는 아이가 처음부터 배울 수 있는 웹 프로그램입니다. `baduk/index.html`을 브라우저에서 열면 바로 실행됩니다.

- **배우기 (12단계)**: 바둑판과 돌 → 번갈아 두기 → 숨구멍 → 돌 잡기 → 단수 → 연결 → 착수 금지 → 패 → 집 세기 → 두 눈 → 따먹기 바둑 → 승부 정하기. 단계마다 직접 돌을 놓는 문제가 있습니다.
- **연습게임**: 따먹기 5줄/7줄, 9줄 바둑. 무르기, 힌트, 위험한 돌(단수) 표시, 수마다 코치 한마디.
- **실전게임**: 9줄/13줄, 덤 6.5. 무르기와 힌트 없음. 이기면 그 단계에 별을 받고 다음 단계가 추천됩니다. 끝나면 집과 죽은 돌을 자동으로 계산합니다.
- **AI 상대 1~10단계**: 1단계는 무작위, 2~5단계는 규칙 기반(잡기·도망·단수) 판단에 실수가 섞임, 6~10단계는 몬테카를로 탐색(수읽기 횟수 400 → 7000회).
- **AI 선생님**: Claude 아티팩트로 열면 Claude가 판 상황(단수인 돌, 엔진 추천 수, 형세)을 받아서 아이 눈높이로 대답합니다. 게임이 끝나면 복기도 해 줍니다. 그냥 브라우저로 열면 돌돌이가 기본 질문(규칙, 단수, 집, 패, 눈, 덤)과 힌트에 답합니다.

`baduk/app.html`은 아티팩트용 본문, `baduk/index.html`은 바로 열 수 있게 문서 틀을 씌운 같은 내용입니다.
