# 씽씽 직업 자동차 🏙️

8살 아이가 바로 즐길 수 있는 브라우저 자동차 게임입니다. 도시에서 일하는 자동차를 직접 운전하며 임무를 수행해요.

## 자동차와 임무
| 자동차 | 임무 |
|---|---|
| 🚓 경찰차 | 도망가는 도둑 차를 쫓아가 잡기 |
| 🚒 소방차 | 불난 가게 앞에서 💦 버튼을 꾹 눌러 불 끄기 |
| 🚑 구급차 | 다친 사람을 태워 병원으로 |
| 🚕 택시 | 손님을 태워 목적지까지 |
| 🚌 버스 | 정류장 3곳 순서대로 돌기 |
| 🚛 청소차 | 길에 떨어진 쓰레기 5개 치우기 |
| 🚚 택배차 | 물류창고에서 택배를 싣고 집까지 배달 |
| 🛻 견인차 | 고장난 차를 정비소로 끌고 가기 |

## 조작
- 화면 버튼: ◀ ▶ 방향, 🚀 출발, 🔽 후진, 특별 버튼(🚨 사이렌 / 💦 물 / 📣 경적)
- 키보드: 방향키 또는 WASD, 스페이스 = 특별 버튼, M = 소리 끄기, Esc = 자동차 바꾸기

## 실행
`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 외부 의존성은 Google Fonts(Jua) 하나뿐이며, 없어도 동작합니다.
